# Austria Other Key Workers — Promotion Matrix

## Scope

Exact Red-White-Red Card — Other Key Workers route. This document does not promote the broader Austria work umbrella.

## Current authoritative gates

The Austrian migration portal currently specifies a 2026 gross monthly statutory minimum of €3,465, a labour-market test, and a minimum 55-point score. The route is valid for 24 months. citeturn0search3

### Evidence matrix

| Gate | Required evidence | Status |
|---|---|---|
| Salary | Prospective employer's statutory minimum remuneration | Evidenced |
| Labour-market test | AMS test / no equally qualified registered jobseeker available | Evidenced |
| Points | Qualification, work experience, age, language and applicable categories | Partial — final regression validation open |
| Identity | Passport/travel document and current photo | Evidenced |
| Insurance | Comprehensive health insurance evidence | Evidenced |
| Qualification | Diploma/certificate or university-admission/tertiary evidence as applicable | Evidenced |
| Work experience | Testimonials/work certificates | Evidenced |
| Language | Recognised German/English certificate where claimed | Evidenced |
| Criminal record | Current certificate where authority requires it | Conditional / authority-dependent |
| Translation/legalisation | German/English translations and legalisation where required | Conditional |

The official portal states that authorities may require additional documents case-by-case and recommends a recent criminal-record extract for initial applications. Originals and copies are required, with translations where documents are not in German or English. citeturn0search3

## Important distinction

Salary, labour-market test and points are separate eligibility gates. Possessing the minimum salary does not substitute for the points or labour-market test.
