# Italy 2026 Flussi — Promotion Matrix

## Scope

This is a temporal 2026 non-seasonal subordinate-work route. It must not be treated as a generic permanent Italy work pathway.

## Promotion gates

| Gate | Requirement | Status |
|---|---|---|
| Annual quota | 2026 non-seasonal subordinate allocation and click-day/quota scope | Evidenced |
| Employer | Eligible employer initiates the nulla-osta process | Open — final matrix |
| Labour-market / nulla-osta | Current employer-side preconditions and documentary declarations | Open |
| Sector/country treatment | Applicable 2026 quota allocation and eligible categories | Open |
| Compensation | Applicable employment remuneration / contract evidence | Open |
| Applicant evidence | Identity, entry/visa and employment documents | Open |
| Timing | 2026 application window and quota availability | Evidenced |

## Safety rules

- Never infer a universal applicant proof-of-funds amount from the annual quota framework.
- Never treat the 2026 quota route as evidence that generic Italy work authorization is available outside its scope.
- Keep employer-side nulla-osta evidence separate from applicant-side visa/entry evidence.
- Preserve effective dates because quota and click-day rules are temporal.
