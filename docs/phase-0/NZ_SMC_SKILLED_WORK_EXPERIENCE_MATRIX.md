# New Zealand SMC — Skilled Work Experience Promotion Matrix

**Scope:** Exact child route `NZ-smc-skilled-work-experience`. This matrix does not promote or provide evidence for the `NZ-skilled` umbrella or the other SMC child routes.

## Authoritative route gates

| Gate | Current rule | Evidence / implementation state |
|---|---|---|
| Skilled employment | ANZSCO skill level 1–3; accredited-employer employment/job offer; at least 1.1× the applicable SMC wage threshold for standard occupations | Evidenced |
| Relevant work | At least 3 years of directly relevant work experience | Evidenced |
| NZ skilled work | Additional 2 years in New Zealand in an ANZSCO 1–3 role at the applicable threshold | Evidenced |
| Direct relevance | Experience must relate to the current skilled job/job offer; immigration officer may perform a substantial-match assessment | Evidenced |
| Self-employment | Cannot be counted as relevant work experience | Evidenced |
| Red List | Ineligible for this pathway | Matrix encoded below |
| Amber List | Higher route-specific requirements | Matrix encoded below |
| Wage effective date | Threshold is tied to the applicable historical rate when qualifying NZ skilled work starts; the applicable rate must be maintained under the current rules | Evidence present; regression cases required |
| Evidence | Employment agreement/job description, hours/remuneration and earnings/tax/service evidence as applicable | Evidenced; route-specific regression required |

## Red List gate

A current job or job offer on the Red List, or an ANZSCO skill level 4 or 5 occupation, is not eligible for this pathway. The current official Red List includes:

| ANZSCO | Occupation |
|---|---|
| 451111 | Beauty Therapist |

| 149999 | Hospitality, Retail and Service Manager nec |
| 411611 | Massage Therapist |

**Rule:** Red-list status blocks the Skilled Work Experience pathway; it does not imply ineligibility for every other SMC pathway.

## Amber List gate

Amber occupations remain eligible for this pathway only when the additional requirements are satisfied:

1. Pay at least **1.2×** the applicable SMC wage threshold.
2. Have at least **3 years** of relevant work experience in New Zealand in an ANZSCO 1–3 occupation.
3. Have an additional **2 years** of skilled work experience in New Zealand in an ANZSCO 1–3 occupation paid at least 1.2× the applicable threshold.

## Wage regression matrix

The current INZ wage table gives the SMC median threshold and the 1.1× / 1.2× Skilled Work Experience rates by the date qualifying NZ skilled work began. Current values include **$35.00 / $38.50 / $42.00 per hour from 9 March 2026** for threshold / standard 1.1× / amber 1.2× respectively.

Required regression cases:

- standard role beginning from 9 March 2026 → 1.1× threshold;
- amber role beginning from 9 March 2026 → 1.2× threshold;
- historical start date → use the historical rate applicable to that date;
- wage below applicable threshold → qualifying NZ work period must not count;
- wage later reduced below the applicable requirement → subsequent qualifying period must not silently continue counting;
- employment beginning within the applicable five-month visa-grant grace window → apply the documented grace rule where eligible;
- Red List / ANZSCO 4–5 role → route must be blocked regardless of wage.

## Promotion gate

Promotion remains blocked until the implementation has:

- [x] exact child-scoped eligibility, financial and process evidence;
- [x] Red/Amber authoritative occupation matrix;
- [x] explicit direct-relevance/self-employment rules;
- [ ] executable wage effective-date regression cases;
- [ ] executable Red/Amber route-blocking regression cases;
- [ ] final candidate-to-canonical promotion validation;
- [ ] data validation/build verification.

## Important distinction

The Red/Amber classification is a **route-specific eligibility gate**, not a country-level status. A blocked Skilled Work Experience route must not cause the recommendation engine to suppress other eligible SMC routes unless their own rules require it.
