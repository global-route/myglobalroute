Hybrid design — what it adds over current

Element Current Hybrid
Visual weight Flex badge row — reads as UI chrome Navy 2px top border + fill — reads as document header
Format Badge + separate spans Single dateline: Brand · version · status · source · date
Edition versioning None — no way to distinguish editions v2026.11 — year.month edition tag on every post
Multi-edition linking None supersededBy link in watermark — older editions stay live, link to current
Archived state None Grey border + "Archived — verified at time of publication"
High-risk notice None in watermark Appended to independence notice line for WAA corridor posts
Unaudited signal Amber badge — easy to miss Amber 2px top border — visible at a glance, creates audit queue
