```

├── 01-germany-visa-reality-for-africans.md

├── 03-canada-visa-rejection-rates-2026.md

├── 05-professional-playbook-uk-skilled-worker.md
├── 06-business-playbook-us-llc-setup.md
├── 07-case-study-chisom-canada.md
└── _INDEX.md (metadata for all posts)
```

### Front Matter Format (for each post)

```yaml
---
title: "Post Title Here"
date: 2026-01-15
author: "Global Route Team"
category: "Category Name"
keywords: "keyword1, keyword2, keyword3"
image: "/public/assets/blog/image-name.jpg"
readTime: "8 min"
featured: true/false
---
```

### Blog Page Functionality

1. **Dynamic loading** - Reads all markdown files from `/src/content/blog/`
2. **Category filtering** - Filter by category (Country Audits, Playbooks, etc.)
3. **Search** - Full-text search across post titles + content
4. **Sorting** - Date (newest first), read time, popularity
5. **Related posts** - Suggests similar posts based on category/keywords

## ✅ Quality Checklist (Each Post)

Before publishing, each post must have:

- [ ] Keyword research (target 1-2 primary keywords)
- [ ] Fact-checked (all claims backed by sources)
- [ ] Structured (headings, tables, lists for scannability)
- [ ] Actionable (clear next steps/resources)
- [ ] Updated metadata (title, description, keywords, image)
- [ ] Internal links (3-5 links to related Global Route content)
- [ ] External links (sources, credibility)
- [ ] Mobile optimized (tested on phone)
- [ ] Accessibility (alt text on images, semantic HTML)
- [ ] Plagiarism check (original content verified)
