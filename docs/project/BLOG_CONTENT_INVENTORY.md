## Standard post structure (country audits)

1. Evidence status note (approval rates not published, sources dated)
2. Quick Summary box (3-5 bullet points: key figures only)
3. Pathway sections (one H2 per pathway)
   - Official requirements (sourced, dated)
   - Cost breakdown (line items with currency, date, source)
   - Application process from Nigeria (embassy, documents, timeline)

5. Official sources list (government URLs, last checked date)
6. Evidence gate disclaimer (standard block)

- Every cost figure needs: currency, amount, effective date, source URL
- No approval rates unless the authority publishes them
- No em dashes — use hyphens
- No emojis in body text
- Word count target: 1,500-2,500 words
- 1 YouTube embed per post (verified video ID)
