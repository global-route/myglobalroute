```html
<div class="video-embed">
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" title="TITLE" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>
</div>

*One sentence describing what the video covers and why it is relevant.*
```

## How to find the right video

1. Go to YouTube
2. Search the query listed below
3. Pick the most official source: government ministry, embassy, official university, or well-known immigration authority channel
4. Avoid: agent channels, paid promotion videos, unverified personal vlogs
5. Copy the 11-character video ID from the URL: `youtube.com/watch?v=VIDEO_ID`
6. Add the embed block to the post and set `image:` frontmatter if you also have a photo

## How to add an embed once you have the video ID

Open the post file and find the first `## ` heading after the intro paragraph. Add the embed block immediately after that heading's content, before the next `## ` heading.

Example — if the post has:

```
## Standard work visa

Your employer must apply...
```

Add after the first paragraph:

```
<div class="video-embed">
<iframe width="560" height="315" src="https://www.youtube.com/embed/VIDEO_ID" title="TITLE" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>
</div>

*Brief description of what the video covers.*
```

Then run `npm run build && npx wrangler deploy`.
